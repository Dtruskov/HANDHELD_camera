# HANDHELD_camera

Виртуальная ручная камера в Unity на Windows, управляемая позиционным ARKit-трекингом iPhone.

## Окружение

- Unity **6000.3.6f1**, URP **17.3.0**.
- Live Capture **4.0.1**, Timeline **1.8.10**.
- Unity Pipeline **0.8.0-exp.1** для подключения редактора к установленному Unity CLI / MCP.
- iPhone **14 Pro Max**, iOS **26.6.1** (со слов владельца).
- Картинка на мониторе ПК; собственное iOS-приложение не требуется.

Live Capture и companion apps сняты с поддержки начиная с Unity 6.1. Установка пакета сама по себе не доказывает работоспособность 6DoF и записи на Unity 6.3 / iOS 26. Проверка на реальном телефоне обязательна. [Объявление Unity](https://discussions.unity.com/t/cinematics-virtual-production-package-deprecation-in-unity-6-1/1553433/1).

## Подготовка проекта

При первой успешной компиляции редактор создаёт `Assets/Scenes/HandheldCameraTest.unity`. Повторная команда **Handheld Camera > Prepare Test Scene** не перезаписывает существующую сцену. Исходная SampleScene сохранена.

В тестовой сцене: метровая сетка, куб 1×1×1 м, ориентир высотой 2 м, объекты на разных глубинах, физическая камера, Virtual Camera Device, Shot Player и библиотека дублей. Начальная высота камеры — 1.6 м. Motion Scale — (1, 1, 1), Damping выключен. Take Recorder настроен на 60 fps при создании сцены; перед съёмкой проверь частоту в его окне. Дубли сохраняются в `Assets/Recordings`.

Включена работа приложения в фоне. Сохранены подходящие настройки: PC quality, Linear color space, Force Text serialization, Visible Meta Files, Input System. Fixed Timestep 0.02 оставлен: физический шаг не задаёт частоту AR-трекинга.

Старый видеопроход Live Capture (`InjectionPointRenderFeature`) отключён в PC Renderer: он не реализует Render Graph API в URP 17 и вызывает сообщения об ошибке. Для MVP с изображением на мониторе он не нужен. Подготовительный скрипт сохраняет его выключенным; перед будущей реализацией стрима на телефон потребуется отдельное решение совместимости.

Unity CLI подключается к этому проекту через Pipeline: `unity status --json`. Если открыто несколько проектов, команды выполнять с `--project-path C:\Users\user\HANDHELD_camera`.

## Первое подключение

1. Установи на iPhone [Unity Virtual Camera](https://apps.apple.com/app/unity-virtual-camera/id1478175507). Доступность зависит от региона Apple ID. Разреши доступ к камере и локальной сети.
2. Подключи ПК и iPhone к одной локальной сети. ПК может быть подключён кабелем к тому же роутеру. Гостевая сеть с изоляцией клиентов не подходит.
3. Открой `Assets/Scenes/HandheldCameraTest.unity`.
4. Открой **Window > Live Capture > Connections**. Подготовленный **Companion App Server** нужно включить. Если его нет, создай через `+`. Запомни IP и порт, показанные в окне (обычно 9000).
5. Если Connections сообщает о firewall, используй **Configure Firewall** для доверенной частной сети. Не отключай брандмауэр целиком.
6. В приложении выбери сервер ПК; при необходимости введи его IP вручную.
7. Открой **Window > Live Capture > Take Recorder**. Выбери `iPhone Capture`, назначь подключённый телефон в **Client Device**. Actor уже назначен: `iPhone Camera`.
8. Выбери Shot Player `Take Playback` / shot `HandheldTest` как контекст записи. Включи **Live** и открой Game View. Сначала проверь управление в Edit Mode.
9. В приложении открой **Camera Setup**: Motion Scale по X/Y/Z = 1, все блокировки позиции и вращения выключены, Enable Damping выключен. Настройки телефона могут изменить значения редактора после подключения.

## Проверка движения и записи

- Пройди примерно метр вбок: камера должна переместиться примерно на клетку сетки. Затем отдельно проверь вперёд/назад и вверх/вниз.
- Проверь панораму, наклон и крен, а также мелкие движения рук. Позиционное движение должно работать отдельно от вращения.
- Проверь потерю трекинга при закрытии камеры телефона и восстановление после возвращения в освещённую комнату с деталями.
- Запиши 10 секунд через Take Recorder, останови запись, выключи Live и воспроизведи дубль. Проверь сохранённые файлы в `Assets/Recordings` и повторное воспроизведение после переоткрытия сцены.
- Для теста сглаживания включи Enable Damping, сравни с выключенным состоянием, затем верни выключенное состояние для сохранения ручной тряски.

**Reset Pose** в официальном приложении возвращает позицию к origin и **не сбрасывает вращение**. **Reposition** позволяет временно отключить AR-влияние, переместить телефон и включить его снова. Полный Recenter с заданной позицией и ориентацией ещё требует отдельной проверки/доработки; не считать Reset Pose его полным эквивалентом.
